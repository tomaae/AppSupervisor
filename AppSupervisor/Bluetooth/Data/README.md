# Bluetooth company identifiers

`company_ids.json` is an offline snapshot of Nordic Semiconductor's
`bluetooth-numbers-database` at commit
`7e410dae9411960888e852bf868e60626eca3caf`.

Source: <https://github.com/NordicSemiconductor/bluetooth-numbers-database>

The database mirrors the Bluetooth SIG Assigned Numbers company identifiers.
It is used only to label company IDs carried in manufacturer-specific Bluetooth
advertising data. The company is a hint about the advertising payload owner and
may differ from the device's consumer-facing brand.
